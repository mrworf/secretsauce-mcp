## Compatibility and limits

New explicit transport/auth state uses managed format 4; older binaries must reject it. Downgrade requires coherent compatible prior state under existing quiescent recovery procedures, never reinterpretation of None. Portable archives exclude live None acknowledgment; restored None is a blocked proposal until fresh current Owner approval. TLS remains implicit TLS, not STARTTLS. Browser HTTPS and encrypted managed storage remain required. Plain SMTP is the Product Owner's explicitly accepted network-hop risk, not an inferred relaxation.

No M24 requirement is deferred. No production deployment or external LLM connection is claimed; the existing exception covers only actual external ChatGPT/Codex validation, while all feasible local checks are performed.
