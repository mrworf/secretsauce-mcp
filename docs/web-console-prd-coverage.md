## Status key

- **Verified:** selectively inspected repository evidence; it does not certify end-to-end console behavior.
- **Specified:** required behavior comes from the row's requirement ID or named PRD heading/companion.
- **Gap (spec):** absent or materially ambiguous required behavior, with a stable gap ID.
- **Gap (implementation):** demonstrated missing implementation after adequate inspection; not used to judge future product-definition readiness.
- **Unverified:** future implementation or test execution is outside this definition review. All console backend/test cells say this explicitly.
- **N/A:** a genuinely inapplicable surface, with a reason.

All management mutations require current server-side role enforcement and the durable audit gate; high-risk actions also require the specified recent authentication. The instance contains one organization: no tenant IDs, cross-tenant role scopes, subscriptions, SSO or custom-role workflows are inferred. Each required positive/negative test is a future validation obligation unless a repository citation explicitly says otherwise.
