Runtime reachability assessment: the critical proxy-addr advisory concerns trust-subnet IPv4-mapped forwarding via Express. SecretSauce serves node:http directly, does not use Express proxy trust, and ignores caller forwarded headers; required forged-header tests pass. SDK OAuth-client authorization-server credential forwarding is a client-helper advisory; this server implements its own OAuth server and pinned metadata fetch, without that outbound OAuth helper. Hono/node-server route/static/CORS/JSX/body helper advisories concern unused adapters; the application uses node:http, allowlisted static assets and bounded own parsers. These assessments distinguish installed dependency risk from a demonstrated gateway exploit; they do not claim package security.

Secretlint's pattern dependency tree includes braces/micromatch and parsing helpers. Catalogue regex input and worker execution are bounded; preview and name-only worker deadlines/heap/slots terminate hostile matches, scanner pool contains scan time/queue/capacity. fast-uri/js-yaml occur in the scanner dependency tree; gateway destinations and pinned metadata use WHATWG URL and own special-use validation. Imported YAML uses bounded own input paths/strict schemas rather than host reads. Existing negative/resource tests and full-suite verification remain required.
