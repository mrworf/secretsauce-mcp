## Required supporting changes and compatibility

`consoleServicePage.ts` only adds the common unsaved-account navigation guard. `consoleSettingsPage.ts` only routes browser history to People/detail and guards unsaved account work; it changes no M24 settings behavior. New account metadata requires encrypted identity format 3; startup, managed loading and interrupted restore cleanup agree. Older format-2 binaries fail closed. Old `people/change` retains Owner lifecycle operations but rejects role changes; the revision-bound account endpoint owns that operation. Deployment guidance documents this intentional closure of stale role writes.

Contact/role changes retain password, Authenticator, lifecycle and identity while revoking generation-bound authority. Before-rename uncertainty leaves the old contact/role and revokes old authority on restart; it does not invent a successful edit or remove factors. Notification failure remains an independent outcome. Dates never grant authority. No M24 SMTP mode or populated settings implementation is included, and no M23 requirement is deferred. Implementation completion does not imply deployment or external ChatGPT/Codex acceptance.
